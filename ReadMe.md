# Data Science Fundamentals Assessment

A beginner-friendly project demonstrating:
- Python variables, operators, conditions, and data structures
- Pandas DataFrame creation, inspection, filtering, sorting, and grouping
- Descriptive statistics using Pandas/NumPy
- Data visualization using Matplotlib
- Basic data-quality checks

## Setup
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

The script creates `student_scores.png` and `study_hours_vs_score.png`.
The dataset is illustrative and contains six fictional student records.
